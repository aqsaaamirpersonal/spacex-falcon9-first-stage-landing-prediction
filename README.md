# SpaceX Falcon 9 First Stage Landing Prediction

## IBM Applied Data Science Capstone Project

### Project Overview
This project analyzes SpaceX Falcon 9 launch data to predict whether the first stage of a Falcon 9 rocket will successfully land.

The main objective is to explore launch data, identify important factors affecting landing success, and develop machine learning models for prediction.

### Project Objectives
- Collect SpaceX launch data using the SpaceX API.
- Extract additional information through web scraping.
- Clean and prepare the collected data.
- Perform Exploratory Data Analysis (EDA).
- Analyze launch data using SQL.
- Create interactive visualizations using Folium and Plotly Dash.
- Build and evaluate machine learning classification models.

### Project Notebooks
1. `01_data_collection.ipynb` – SpaceX data collection.
2. `02_data_wrangling.ipynb` – Data cleaning and preparation.

### Tools and Technologies

- SQL
